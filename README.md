# 개발 블로그

Hugo 정적 사이트 생성기와 Toha 테마로 만든 한국어 개발 블로그입니다.

## 기술 구성

- `Hugo Extended 0.163.3`
- `Toha 4.16.0`
- `Go 1.25`
- `Node.js 22`

## 사용 방법

도구와 의존성을 설치합니다.

```bash
mise install
mise exec -- npm ci --include=dev
```

로컬 개발 서버를 실행합니다.

```bash
mise exec -- npm run dev
```

사이트는 `http://localhost:1313/devlog/`에서 확인할 수 있습니다.

배포 결과를 만들고 링크와 한국어 전용 구성을 검증합니다.

```bash
mise exec -- npm run build
npm run check
```

## 글 작성

글은 `content/posts/분류/글-이름/index.ko.md`에 작성합니다. 현재 분류는 프로젝트(`project`), 유니티(`unity`), 안드로이드(`android`)입니다. 제목, 요약, 게시일, 수정일, 태그와 사이드바 정보를 문서 머리말에 등록하고 이미지는 같은 글 묶음의 `images/`에 둡니다.

이전한 기술 글은 원본 저장소의 최초 기록일을 게시일로, 마지막 기록일을 수정일로 사용했습니다. 각 글 끝의 원문 링크에서 기존 기술 블로그 문서도 확인할 수 있습니다. 과거 배포 기록은 당시 도구와 절차를 설명합니다.

내부 게시글 링크는 휴고의 `relref`를 사용합니다. 한국어만 제공하므로 영어 번역 파일이나 언어 선택 메뉴를 추가하지 않습니다. 검증기는 게시글·이미지·문서 앵커와 검색 색인을 검사하고 영어 페이지가 남아 있으면 실패합니다.
